# 📦 Система построена! Полный список компонентов

## 📂 Структура файлов

### ⚙️ Backend (Python + SQLAlchemy)

| Файл | Назначение |
|------|-----------|
| `backend/config.py` | Конфигурация подключения к MySQL (переменные окружения) |
| `backend/database.py` | Инициализация SQLAlchemy engine, sessionmaker, Base |
| `backend/models.py` | ORM модели для всех таблиц БД (User, Client, RepairRequest и т.д.) |
| `backend/auth.py` | Функции аутентификации: хеширование паролей (bcrypt), проверка пользователя |
| `backend/queries.py` | Бизнес-логика: CRUD операции, отчеты, динамический расчет стоимости |
| `backend/__init__.py` | Пакет backend |

### 🎨 Frontend (PyQt6)

#### Главное окно и вход

| Файл | Назначение |
|------|-----------|
| `frontend/main_window.py` | Главное окно приложения, диспетчер ролей (выбирает интерфейс по роли) |
| `frontend/login_dialog.py` | Диалог входа: проверка телефона и пароля, блокировка неактивных пользователей |
| `frontend/__init__.py` | Пакет frontend |

#### Интерфейсы по ролям

| Файл | Назначение |
|------|-----------|
| `frontend/roles/operator_window.py` | Интерфейс оператора-приемщика: управление клиентами, создание заявок, фильтрация |
| `frontend/roles/master_window.py` | Интерфейс мастера: список назначенных заявок, журнал работ, управление запчастями |
| `frontend/roles/admin_window.py` | Интерфейс администратора: персонал, справочники, отчеты (должники, дефицит, неиспользованные мастера) |
| `frontend/roles/__init__.py` | Пакет roles |

#### Диалоги и компоненты

| Файл | Назначение |
|------|-----------|
| `frontend/roles/dialogs/client_dialog.py` | Диалог добавления нового клиента (ФИО, телефон, паспортные данные) |
| `frontend/roles/dialogs/request_dialog.py` | Диалог создания заявки (выбор клиента/устройства, описание проблемы, назначение мастера) |
| `frontend/roles/dialogs/device_dialog.py` | Диалог регистрации устройства (тип, модель, серийный номер) |
| `frontend/roles/dialogs/__init__.py` | Пакет dialogs |

### 📋 Конфигурация и инициализация

| Файл | Назначение |
|------|-----------|
| `main.py` | **Точка входа приложения** — запускает PyQt приложение |
| `init_db.py` | Инициализация БД: создание таблиц, заполнение тестовыми данными |
| `requirements.txt` | Зависимости Python |
| `.env` | Переменные окружения для подключения к БД |
| `README.md` | Документация проекта |

## 🎯 Функции по ролям

### 👨‍💼 Администратор
✅ Управление персоналом (создание, редактирование, блокировка)  
✅ Управление справочниками (услуги, статусы, приоритеты)  
✅ **Отчет должников** — невыплаченные завершенные заявки  
✅ **Отчет дефицита** — запчасти с остатком ≤ 5 шт  
✅ **Отчет мастеров** — те, кто не работает сейчас  
✅ **Анализ отмен** — отмененные заявки за последний месяц  

### 📋 Оператор-приемщик
✅ Поиск/регистрация клиентов (по телефону или ФИО)  
✅ Регистрация оборудования  
✅ Создание заявок на ремонт  
✅ Назначение мастеров на заявки  
✅ Просмотр всех заявок с фильтрацией по датам  

### 🔧 Мастер по ремонту
✅ Просмотр только своих назначенных заявок  
✅ Ведение журнала выполненных работ  
✅ Добавление услуг из прайс-листа  
✅ Списание запчастей со склада  
✅ Управление статусом заявки (На выполнении → Выполнена → Приостановлена)  
✅ Загрузка фотографий дефектов

## 🗄️ Реализованные бизнес-правила

| Правило | Реализация |
|---------|-----------|
| ✅ Аутентификация по телефону | `backend/auth.py` + `login_dialog.py` |
| ✅ Блокировка неактивных пользователей | Проверка `is_active` при входе |
| ✅ Хеширование паролей | bcrypt в `auth.py` |
| ✅ Обновление `last_auth_at` | При успешном входе |
| ✅ Динамическая адаптация интерфейса | `main_window.py` выбирает окно по роли |
| ✅ Каскадное удаление | `ON DELETE CASCADE` для зависимых данных |
| ✅ Запрет удаления связанных данных | `ON DELETE RESTRICT` для основных сущностей |
| ✅ Автоматический складской учет | `deduct_consumable()` в `queries.py` |
| ✅ Динамический расчет стоимости | `calculate_repair_cost()` в `queries.py` |
| ✅ Отчеты по 4 критериям | 4 отчета в `queries.py` + интерфейс администратора |

## 🧪 Тестовые данные

При запуске `init_db.py` заполняются:

- **4 пользователя**: 1 администратор + 1 оператор + 2 мастера
- **2 мастера-профиля** с привязкой к пользователям
- **5 справочников**: статусы, приоритеты, типы ремонта, роли
- **6 услуг** с ценами и длительностью
- **3 клиента** с полными паспортными данными
- **3 устройства** разных типов (ноутбук, смартфон)
- **5 расходных материалов** с разными остатками (включая 0)
- **2 заявки на ремонт** с мастерами

## ✨ Ключевые особенности

🔐 **Безопасность**: Пароли хешируются bcrypt  
🎯 **RBAC**: Разные интерфейсы для разных ролей  
📊 **Отчетность**: 4 встроенных отчета для аналитики  
💾 **Надежность**: Правильные FK constraints (RESTRICT/CASCADE)  
🔄 **Автоматизация**: Автоматический учет склада при списании запчастей  
📱 **Modern UI**: PyQt6 с таблицами, диалогами, фильтрацией
