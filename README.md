# Сервис-Центр Компьютерной Техники — Информационная система

Полнофункциональная десктоп-приложение для управления заявками сервисного центра, написанное на **Python + Qt**.

## 📋 Требования

- **Python 3.9+**
- **MySQL 5.7+**
- Установленные зависимости (см. requirements.txt)

## 🚀 Установка и запуск

### 1. Подготовка окружения

```bash
# Клонируем/скачиваем проект
cd c:\niggeriya

# Создаем виртуальное окружение
python -m venv venv
venv\Scripts\activate

# Устанавливаем зависимости
pip install -r requirements.txt
```

### 2. Настройка базы данных

Отредактируйте файл `.env` и укажите параметры подключения к MySQL:

```env
DB_HOST=localhost
DB_PORT=3306
DB_NAME=service_repair
DB_USER=root
DB_PASSWORD=your_password
```

Убедитесь, что в MySQL создана база данных `service_repair`:

```sql
CREATE DATABASE IF NOT EXISTS service_repair;
```

### 3. Инициализация базы данных

```bash
python init_db.py
```

Это создаст все таблицы и заполнит их тестовыми данными.

### 4. Запуск приложения

```bash
python main.py
```

## ✨ Функциональность по ролям

### 🔐 Администратор
- Управление сотрудниками (создание, редактирование, деактивация)
- Управление справочниками (услуги, статусы, приоритеты)
- Доступ к отчетам:
  - **Контроль задолженности** — список неоплаченных выполненных заявок
  - **Дефицит склада** — запчасти с низким остатком
  - **Эффективность персонала** — мастера без активных заявок
  - **Анализ отмен** — отмененные заявки за последний месяц

### 📋 Оператор-приемщик
- Поиск и регистрация клиентов
- Регистрация оборудования
- Создание заявок на ремонт
- Назначение мастеров
- Фильтрация и просмотр всех заявок по датам

### 🔧 Мастер по ремонту
- Просмотр назначенных заявок
- Поэтапный журнал работ
- Добавление и списание запчастей со склада
- Выбор услуг из прайс-листа
- Изменение статуса заявки
- Загрузка фотографий дефектов и результатов работ

## 🗄️ Ключевые бизнес-правила

✅ **Каскадное удаление**: При удалении этапа работы автоматически удаляются услуги, запчасти и вложения  
✅ **Запрет удаления**: Нельзя удалить клиента, сотрудника или услугу, если на них ссылаются заявки  
✅ **Автоматический учет склада**: При списании запчастей количество на складе уменьшается автоматически  
✅ **Динамический расчет стоимости**: Цена ремонта рассчитывается как сумма услуг + стоимость запчастей  
✅ **Контроль доступа**: Интерфейс адаптируется под права пользователя  

## 🔧 Технологический стек

- **Backend**: Python 3.9+, SQLAlchemy, bcrypt
- **Frontend**: PyQt6
- **Database**: MySQL 5.7+
- **Security**: Bcrypt для хеширования паролей

## 📝 Примечания

- Все пароли хешируются с помощью bcrypt
- Дата/время автоматически сохраняются при создании записей
- Время последней аутентификации обновляется при входе
- Мастера могут назначаться на несколько заявок одновременно
- Заявки и их истории не могут быть удалены (RESTRICT), но записи работ могут быть удалены с каскадом

## 🐛 Известные ограничения

- Фото загруженные в `attachments` хранят только путь (реализация загрузки требует отдельного модуля)
- Пока нет экспорта отчетов в Excel/PDF
- Нет механизма восстановления пароля
